# Development Plan

## Phase 1 — Foundation (this delivery)

1. Create independent sibling project and Vite/React/TypeScript toolchain.
2. Encode and validate the 69-concept catalog, phrase bank, sentence bank and visual manifests.
3. Create a build-time asset-copy allow-list and copy selected approved course assets into this project.
4. Implement versioned IndexedDB repository, JSON backup/import validation, mastery, spacing, scheduler, question factory and analytics structures.
5. Add unit tests plus a Playwright smoke test that verifies routes can be served without cross-project asset URLs.

## Deferred intentionally

- polished final child UI and full interaction components;
- commissioning/importing the 60 approved visual variants;
- filling isolated official MP3 gaps;
- teacher control visuals and hidden-entry interaction;
- real-device visual QA and GitHub Pages deployment;
- backend, account, cloud sync, subscription, shop and notifications.

## Completion gates for this phase

- source course directory has no changes;
- the new project is self-contained;
- content audit reports 69 concepts and the 56/13 curriculum split;
- automated tests cover scheduler, repeat constraints, retry delay, visual selection, analytics, and repository backup semantics;
- production build succeeds.
