# Core Image Prompts

Use the shared style block with every prompt below.

Shared style block:

```text
Use case: scientific-educational
Asset type: Kimi Word Adventure core vocabulary image, square 1024x1024 PNG
Style/medium: warm, polished children's educational illustration for ages 5-6; soft shapes; friendly proportions; consistent simple studio/classroom visual language
Scene/backdrop: clean light background with one or two simple grounding shapes only
Composition/framing: single clear subject, centered, large, readable at small card size
Lighting/mood: bright, gentle, encouraging, classroom-safe
Constraints: no text, no letters, no numbers, no word labels, no emoji, no watermark, no poster layout, no busy background; the image must teach only the target concept
```
